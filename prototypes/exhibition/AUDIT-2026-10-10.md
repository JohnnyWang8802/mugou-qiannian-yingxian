# UI/UX regression audit — 2026-10-10

Scope: isolated `design-review.html`, its three directions and Chinese (Simplified / Traditional) and English interfaces. Production source and Blender geometry were not modified.

## Fixed

| Finding | Resolution | Verification |
| --- | --- | --- |
| Fractional variant URL such as `?v=1.5` indexed a nonexistent direction and failed during initialization | Validate finite integer range and fall back to Quiet | Browser loaded `v=1.5&lang=unknown`; observed Quiet and zh-CN, no console errors |
| At 667×375 the mobile Atlas layout collapsed the model field to zero height; English header items overlapped | Dedicated short-landscape layout, secondary Archive access through Settings | Inspected whole and structure screens; structure viewport 351×198, no horizontal overflow |
| At 320×568 the expanded control panel left only a very small model field | Short portrait panel scrolls within a smaller maximum height | Inspected narrow portrait layout and tested layout matrix |
| Floor change left the old Brackets/Frame/Finial tab selected | Re-render chapter state, reset camera label and restore floor selector focus | Changed Frame → storey 4; no stale active chapter remained |
| Separation slider did not update the toolbar's pressed state | Synchronize `aria-pressed` during slider input without replacing focused input | 50% slider value reported expanded=true |
| Night exhibition Reset reverted to a different material than the initial default | Reset restores the selected direction's default material and Observe mode | Toggled clay off then reset; clay=true in Nocturne |
| Quality setting was inferred from device pixel ratio | Store selected quality independently | Selected Smooth then switched language; quality remained low |
| Several programmatic stops left orbit button state stale | Centralize orbit state updates, including manual keyboard operation and hidden documents | Enabled orbit, rotated with arrow key, reopened Settings; orbit=false |
| Closing a dialog after language change or nested Archive could lose keyboard focus | Bind close handling to the current DOM and a visible trigger | Close after locale change returned to Settings; nested Archive + Escape returned to Archive |
| Detail preset could enlarge geometry across surrounding labels | Route Brackets preset into the dedicated structure observation field | Inspected Brackets at 1280×720 |
| Frame/Finial detail showed a misleading Whole view label | Show selected component in view selector and caption | Inspected Finial screenshot and Frame landscape screenshot |
| Exporting the whole scene could reset a manually chosen view via preset camera fitting | Clone current camera, remove viewport offset, adjust only for export aspect ratio | Exported and opened a real 1920×1080 Finial PNG; current component framing retained |
| English loading text, canvas instructions and failure feedback could contain Chinese | Added translated loading/title/canvas/error messages | Normal loading and all locale switches exercised; failure translations reviewed in source |
| Shader initialization or context loss could leave an unusable scene | Add explicit localized retry overlay; stop rendering after context loss | Source review; GPU context loss and forced shader failure were not simulated |
| Back-forward cache could restore disposed renderer resources | Preserve resources on persisted pagehide | Source review; browser history restoration not separately exercised |

## Checks completed

- TypeScript for the isolated prototype passed.
- Existing production `npm run build` passed.
- Explicit Vite bundle of `design-review.html` passed (temporary output under `/tmp`, no production build-entry change).
- 3 directions × 3 languages at 320×568: all 9 combinations had scrollWidth=320, positive model viewport height and toolbar/header/picker bounds inside the screen.
- Actual screenshot review at desktop 1280×720, portrait 320×568 and landscape 667×375, supplemented by earlier 390×844 and larger desktop checks.
- Front, side, above, below and bracket presets exercised in addition to default full view.
- Floor selection, separation slider, material toggle, reset, quality, locale, orbit cancellation, modal focus and Escape checked.
- Invalid URL fallback tested through a new page load.
- No warnings or errors returned in sampled browser console logs following the tested interactions.
- Export proof: `artifacts/ui-redesign/15-audit-finial-export.png` (1920×1080).
- Landscape proof: `artifacts/ui-redesign/16-audit-landscape.png`.

## Remaining limits

These are browser viewport tests, not physical iOS/Android tests. Reduced-motion handling, resource-load failure, context loss and bfcache branches received source review rather than simulated failure testing. No frame-rate guarantee or archaeological-accuracy certification is implied.

The existing Three.js bundle-size warning remains. The prototype currently exports 1920×1080; production integration still needs the original full export options and a target-device performance pass. No deployment or GitHub push was performed.
